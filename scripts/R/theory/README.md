# scripts/R/theory/

Numerical illustration for the **2×2 competitive-solicitation model** (analytical component). Use R here to
solve/verify the equilibrium numerically and produce comparative statics — e.g. the Sun (2012) result that
spread raises demand only when the average is low, and how soliciting (which compresses spread toward the
truth) helps a high-average firm and hurts a low-average one.

These numerics should **match the analytical claims** in `report/theory/`; the `domain-reviewer` agent
checks that they agree. Follow `.claude/rules/r-code-conventions.md`; publication-ready figures to
`Figures/theory/`.
