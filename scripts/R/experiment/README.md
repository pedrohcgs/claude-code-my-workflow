# scripts/R/experiment/

Analysis for the **consumer-inference experiment** (tests design question (b): whether consumers adjust
their quality inference once they know how reviews were collected).

Discipline:

- **Pre-register** the design, hypotheses, exclusions, and analysis before running (`/preregister`).
- **Power** the design (`/power-analysis`); include attention/comprehension checks.
- Map the outcome (which business is chosen) explicitly back to the model's consumer-inference assumption.

Follow `.claude/rules/r-code-conventions.md`; publication-ready tables/figures to `scripts/R/_outputs/`
and `Figures/experiment/`.
