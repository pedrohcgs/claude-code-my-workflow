# report/experiment/

Drafts for the **consumer-inference experiment** (author's contribution).

Purpose: test whether consumers adjust their quality inference once they learn how reviews were collected
— design question (b), the assumption the 2×2 model rests on. Design: show participants two competing
businesses, one with a tight, solicited-looking distribution and one with a polarized one; vary the
average ratings; observe which is chosen. Pre-register before running (`/preregister`).

If consumers do **not** adjust → soliciting is a straight advantage for strong firms. If they **do** →
soliciting becomes a signal and can backfire. This is what makes the analytical and empirical components
interdependent (see `MEMORY.md`).

Companion analysis: `scripts/R/experiment/`.
