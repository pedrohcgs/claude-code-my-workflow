# Research-slide design

## Message and hierarchy

- Give every slide one sentence the audience should retain.
- Make that sentence visually discoverable within a few seconds.
- Use whitespace and alignment to show hierarchy; avoid decorative boxes that
  compete with the result.
- Alternate dense evidence with sparse synthesis. Split a slide before shrinking
  body text below a legible presentation size.

## Evidence displays

- Prefer a purpose-built figure to a manuscript regression table.
- If a table is necessary, retain only the rows and columns needed for the slide
  and make the focal comparison explicit without altering values or labels.
- Label axes, groups, units, uncertainty, sample, and data source.
- Use vector figures when appropriate and confirm the renderer preserves them.
- Design color encodings to remain distinguishable under common color-vision
  deficiencies and in grayscale; never encode meaning by color alone.

## Equations and notation

- Show only notation needed for the current inference.
- Define symbols before using them and preserve the manuscript's meanings.
- Explain the role of the estimand, parameter, or equilibrium condition in words.
- Move derivations that do not change audience understanding to backup.

## State and motion

Every audited slide should have one explicit state. Do not use Beamer overlays or
RevealJS incremental fragments. If a sequence genuinely needs multiple states,
author separate slides with stable titles or clear step labels.

## Citations and notes

Use concise author–year citations on slides and keep full entries in the
bibliography or backup. Speaker notes should name the key point, planned time,
and backup slide for likely questions; notes do not rescue an unsupported slide.
