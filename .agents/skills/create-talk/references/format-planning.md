# Audience and time planning

Plan in minutes before counting slides. A slide may take seconds or several
minutes; fixed slide-count formulas are unreliable.

## Inputs

- speaking time excluding or including questions;
- expected interruption style;
- audience's field and methodological familiarity;
- venue purpose: hiring, seminar feedback, conference exposure, defense, or
  lightning overview; and
- non-negotiable results, assumptions, or institutional context.

## Timed outline

For each argumentative beat record:

| Beat | Message | Evidence/source | Planned minutes | Backup path |
|---|---|---|---:|---|
| Opening | Question, stakes, contribution | Manuscript location |  |  |
| Design/model | Why the evidence answers the question | Strategy/model location |  |  |
| Main result | Magnitude, units, uncertainty | Output/display |  |  |
| Interpretation | What changes and what does not | Manuscript discussion |  |  |
| Close | One takeaway | Supported synthesis |  |  |

Reserve time for questions or interruptions appropriate to the venue and leave
some slack; a plan that uses every second has already overrun. Rehearse from the
rendered artifact and record actual cumulative time at major transitions.

## Format emphasis

- **Job-market:** establish question and contribution early; demonstrate command
  of the design or model; prepare deep backup for anticipated faculty questions.
- **Seminar:** allow more motivation and methodological discussion, with natural
  stopping points for interruptions.
- **Conference:** carry one central contribution and result; keep literature and
  robustness compact.
- **Defense:** make the portfolio and committee-specific methodological choices
  explicit while preserving a coherent central arc.
- **Lightning:** one question, one visual result, one takeaway; omit equations
  and tables unless indispensable.
