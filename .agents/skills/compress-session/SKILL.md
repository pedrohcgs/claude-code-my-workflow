# Compress the session

Create `quality_reports/session_logs/YYYY-MM-DD_<topic>.md` from the current work. This is a durable continuation note, not a transcript and not a substitute for Codex's own context management.

Record the goal, current state, validated results, decisions with rationale, changed or relevant files with line pointers, open risks, and the next one to three concrete actions. State commands already run and their outcomes so a later session does not repeat them blindly. Exclude secrets, verbose logs, and speculation. If context may be lost, make the note self-contained enough for another Codex session to resume from repository state.
