### Mechanical & evaluation upgrades

- **Trigger evals before rewriting skill descriptions** — measure routing with `/skill-doctor` and eval cases (`scripts/run-skill-eval.sh`) before rewriting `description:` fields.
- **Disposition draw in code** — `editor.md` uses `RUN_CONFIG` dispositions when passed; `/review-paper`'s pre-flight should sample them in code (weighted `random.choices`), so `--variance` measures real sampling variance rather than a model's idea of a random draw.
- **Gate mutation testing** — delete or corrupt one line at a time in gated surfaces (README tables, skill frontmatter, hook wiring) and report edits no backtest gate catches; complements `/vaccinate`'s seeded defects.
- **Eval harness hygiene** — JSON output so each arm reports cost and tokens alongside quality; frozen or disabled web access so both arms see the same inputs.
- **`/promote-memory --from-history`** — opt-in subagents read past transcripts for broken, unused, or repeatedly-corrected rules; skip sessions that touched restricted paths.
- **Replayable qualification fixtures** (`qualification-fixtures/` with per-defect branches, prompts, replay script) — the ledger records results; fixtures would make them replayable.
- **Interface/version feature-support matrix** — deferred; maintenance cost vs. per-surface caveats inline.
- **`/promote-memory` autonomous mode (`--auto`)** — defer until telemetry shows how often 5-of-5 votes happen and how often the user approves them.
- **`/compress-session --restore <path>`** — read a prior compression file and pre-populate the new session's context with the structured summary.
- **`/humanize --strict <threshold>`** — gate-refuse `/commit` if HIGH-severity tells per 1000 words exceed `<threshold>`.
- **Passport `claim_audit` schema extension** — extend `passport.yaml` beyond numeric-claim provenance to citation provenance + literature-corpus state.
- **Cost-Conscious Composition telemetry** — measure the actual cost impact of the 70/20/10 routing against an unpinned baseline.
